# День 22. Первый RAG-запрос

Вопрос идёт двумя путями. Без RAG модель отвечает по общим знаниям и не видит книгу. С RAG тот же вопрос переводится на английский, по вектору находятся 4 фрагмента «Boston Cooking-School Cook Book», и модель отвечает только по ним.

В ответе чата на http://127.0.0.1:8080/ оба текста стоят рядом. Под ними таблица из 10 контрольных вопросов: ожидание, раздел книги и пометки, совпали ли факты и нашёлся ли источник.

Прогон DeepSeek по этим десяти вопросам: нужный раздел нашёлся во всех десяти. Ответ с фрагментами совпал с ожидаемыми фактами тоже во всех десяти. Без книги — в одном, голландский соус: кайенский перец модель назвала и без рецепта.

Индекс тот же, что на дне 21: `/home/troot/cookbook/index/`, структурная нарезка, 1360 чанков.
