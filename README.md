# День 29. Оптимизация локальной LLM

Чат на http://127.0.0.1:8080/ — кулинарный помощник на локальной Qwen. Ответ идёт из самой модели, без поиска по книге. Файл модели — Q4_K_M, 9.7B. Другого квантования на хосте нет, поэтому оставлен уже загруженный Q4_K_M.

Для этой задачи запрос к Local-Qwen другой, чем дефолт Modelfile:

- температура 0.15 вместо 0.4
- не больше 320 токенов ответа
- окно контекста 8192 вместо 32768
- внутренние рассуждения выключены (`reasoning_effort: none`)
- шаблон: короткий кулинарный ответ из знаний модели, без поиска по книге

Кнопка «Локальная модель» в настройках гоняет четыре рецепта (кофе, чай, какао, голландский соус) дважды: сначала дефолт хоста, потом эти параметры. В карточке видны качество, время и токены. Одни и те же фрагменты книги уходят в оба прогона.
