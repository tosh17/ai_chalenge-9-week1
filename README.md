# День 21. Индексация документов

## Задание

Текст нарезается на чанки, для каждого считается эмбеддинг, индекс сохраняется локально. У чанка есть метаданные `source`, `title`, `section`, `chunk_id`. Две стратегии нарезки сравниваются на одном корпусе: фиксированное окно и структура по главам и рецептам.

## Что сделано

Корпус — общедоступная книга Fannie Merritt Farmer, *The Boston Cooking-School Cook Book* (издание 1910, Project Gutenberg №65061). Это поваренная книга примерно на тысячу блюд. Ollama с моделью `nomic-embed-text` работает в контейнере на `10.10.1.101:11434`.

Индекс на локальном сервере: `/home/troot/cookbook/index/`. Чат снова кулинарный. Отдельной страницы нет: вопрос в http://127.0.0.1:8080/ возвращает два ответа (окно и главы/рецепты) и таблицу сравнения стратегий.

| | фиксированное окно | по главам и рецептам |
| --- | --- | --- |
| чанков | 1301 | 1360 |
| средняя длина | 999 | 806 |
| разделов | 39 | 916 |
| заголовков разрезано окном | 589 | 0 |

Текст книги около 1,1 млн символов, оценка объёма 614 страниц.

Повторный прогон: `/home/troot/cookbook/index-bin -corpus /home/troot/cookbook/corpus -out /home/troot/cookbook/index -ollama http://10.10.1.101:11434`.
