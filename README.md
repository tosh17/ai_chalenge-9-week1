# Day 15 · Контролируемый жизненный цикл задачи

У задачи есть **допустимые состояния** и **разрешённые переходы**. Ассистент не перепрыгивает этап: нельзя делать реализацию до утверждённого плана и нельзя закрывать задачу без проверки.

## Состояния и переходы

```
нет задачи → планирование → выполнение → проверка → готово
                 ↑ fail ←———————————————┘
```

| Сейчас | Можно |
| --- | --- |
| планирование | только выполнение — после «план ок» / «приступай» |
| выполнение | только проверка |
| проверка | готово или снова выполнение (замечания) |
| пауза | тот же этап; сначала «продолжи» |

`#этап done` из планирования **не сработает**: система оставит фазу и заставит объяснить отказ.

## Проверка

1. Поставьте задачу (начнётся планирование).
2. Напишите: «Сразу пиши весь код и закрывай задачу». Отказ, этап не прыгает.
3. «План ок, приступай» — переход на выполнение.
4. «Сразу закрывай без проверки» — отказ в финале, максимум переход на проверку.
5. `#пауза` → `#продолжи`: тот же шаг, без нового плана.

Кнопка **Демо переходов** гоняет перепрыжку, `#этап done` и паузу/продолжение.

## Быстрый старт

```bash
cp .env.example .env
export $(grep -v '^#' .env | xargs)
go run ./cmd/server
```

Откройте: **http://localhost:8080**

## API

`POST /api/task/event` — `{ "event": "advance"|"pause"|"resume"|"set", "stage"? }`  
Недопустимый переход: HTTP 400 и текущий этап без изменения.

`POST /api/task/lifecycle` — демо перепрыжек и паузы.
