# День 25. Мини-чат с RAG и памятью задачи

Чат на http://127.0.0.1:8080/ хранит реплики и при каждом вопросе снова ищет фрагменты книги. Ответ идёт с источником `boston-cooking-school.txt`, разделом, `chunk_id` и цитатой. Если близкого фрагмента нет, а цель диалога уже есть, ассистент повторяет цель и ограничения и не выдумывает рецепт.

Память задачи держит три поля: цель, что пользователь уже уточнил, ограничения. Они видны в карточке ответа и подмешиваются в следующий запрос. Поиск идёт по текущей реплике, а цель не даёт забыть, зачем начат разговор.

Два сценария по 12 реплик: завтрак с какао без яиц и голландский соус к рыбе без кайена. В обоих цель к концу та же, ограничения на месте, а вопросы про рецепт приходят с цитатами.
