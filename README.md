# День 30. Локальная модель по сети

Основа — чат дня 20. Модель — Qwen на домашнем сервере, OpenAI-совместимый HTTP API. Чат по-прежнему на http://127.0.0.1:8080/.

## Задание

Локальная LLM:

- на домашнем сервере
- с HTTP API
- с чатом

Проверить доступ по сети, стабильность на нескольких запросах и базовые ограничения: rate limit и max context.

## Что сделано

Модель уже стоит на `10.10.0.220:8787`. Чат ходит в `http://10.10.0.220:8787/v1/chat/completions`, модель `qwen-local` (Q4_K_M, 9.7B). Это провайдер по умолчанию.

Кнопка «Проверить модель» в настройках вызывает `POST /api/day30` и показывает карточку:

| Проверка | Как |
| --- | --- |
| Сеть | `GET /v1/models`, время и id модели |
| Стабильность | три коротких запроса подряд, у каждого должен быть текст ответа |
| Контекст | окно файла из `/api/show`, `num_ctx` из Modelfile, лимит счётчика чата |
| Rate limit | заголовки `Retry-After` / `RateLimit` и ответы `429` |

На этом хосте отдельного лимита запросов нет: заголовков нет и `429` не приходит. Окно файла — 262144 токена, для генерации в Modelfile стоит `num_ctx` 32768. Счётчик чата режет запрос на `LOCAL_CONTEXT_LIMIT` (256000).
