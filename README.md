# День 33. Ассистент поддержки s1

Сервис смотрит домашний сервер s1 (`10.10.1.101`). Модель выбирает инструмент, сервер сам выполняет узкую команду `docker`. Произвольный shell ей не отдаётся.

Вопрос задаётся о живом сервисе. Ассистент читает список контейнеров, статус и хвост логов, сверяет FAQ и отвечает двумя разделами: причина и рекомендация.

В логе `ollama` сегодня есть предупреждение: для `nomic-embed-text` запрошен контекст `8192`, а окно обучения модели `2048`.

```bash
set -a && source .env && set +a
export S1_HOST=troot@10.10.1.101
go run ./cmd/ops support -q "Почему Ollama пишет, что запрошенный контекст слишком большой для модели?"
```

Страница на самом s1: http://10.10.1.101:8095/

Кнопка «Что запущено» показывает контейнеры.

## Откуда данные

- Логи: `service_logs` → `sudo -n docker logs`
- FAQ: `docs/faq.md`
