# День 35. Docker на s1

Задача: смотреть, что уже запущено на домашнем сервере, рекомендовать образ и поднимать только учебный контейнер. GitLab, Ollama и runner не останавливаются.

Модель не получает shell. Она выбирает инструменты `list_services`, `list_images`, `write_file`, `run_demo`, `remove_demo`. Процесс сам собирает `sudo -n docker` и пропускает только имя `ops-*`, образы `nginx:alpine` и `alpine:3.20`, порт `10.10.1.101:18080–18090`. Без ключа ту же цель выполняет запасной путь.

```bash
S1_HOST=troot@10.10.1.101 go run ./cmd/ops docker -goal "Покажи, что запущено, порекомендуй образ для простой страницы и подними его на порту 18080"
```

Страница появится на `http://10.10.1.101:18080`. Имя контейнера начинается с `ops-`. На пробном запуске модель выбрала `ops-nginx-18080`. Убрать: та же команда с целью «Убери контейнер ops-nginx-18080».

На самом s1 `S1_HOST` пустой, команды идут локально. Сервис слушает `OPS_ADDR=10.10.1.101:8095` с `OPS_INPROCESS=1`.

Поддержка по живым логам и правка файлов настроек остаются в этом же бинарнике: первое поле и блок «Настройки».
