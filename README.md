# День 24. Цитаты, источники и анти-галлюцинации

Ответ строится только по чанкам, которые прошли порог 0.75. Рядом с текстом стоят источник `boston-cooking-school.txt`, раздел, `chunk_id` и дословная цитата. Если после порога чанков нет, модель не вызывается: ассистент отвечает «Не знаю» и просит уточнить блюдо.

В карточке на http://127.0.0.1:8080/ видны ответ и цитаты.

На прогоне источники и цитаты есть у всех десяти. Числа ответа лежат в цитатах у девяти. У голландского соуса одно число в ответе не нашлось в показанной цитате. Вопрос про замену масла в двигателе даёт «Не знаю» без вызова модели.
