# Ассистент /help

Команда отвечает на вопросы о репозитории. Она не подбирает рецепты и не читает короткую память диалога.

## Как вызвать

В поле чата:

```
/help как устроен проект
/help какие есть HTTP API
/help где схемы данных
/help какая сейчас ветка
```

Регистр команды не важен. Текст после `/help` — вопрос. Голый `/help` подставляет вопрос про каталоги, API и саму команду.

На пустом чате те же вопросы висят кнопками под приветствием. Состояние индекса — в настройках, блок «Документация», данные с `GET /api/help`.

## Что происходит на сервере

1. `internal/handler` узнаёт команду и не вызывает кулинарный `agent.Handle`.
2. `internal/rag` ищет 5 чанков в индексе `README.md` и `docs/**/*.md`.
3. Клиент MCP вызывает `git_branch`, `list_files` (глубина 2) и `git_diff`. Патч запрашивается, только если вопрос про изменения.
4. Промпт собирается из трёх блоков: репозиторий, документация, вопрос.
5. Выбранный провайдер (`local` или `deepseek`) отвечает через `Agent.Complete` — один вызов без инструментов и без слоёв памяти. Если он недоступен, тот же промпт уходит во второй провайдер.
6. В JSON ответа поле `help` несёт ветку, источники и имена инструментов. UI рисует карточку под пузырём.

Если модель недоступна, ответ всё равно 200: в пузыре ветка, дерево и выдержки чанков. В `help.degraded` стоит `true`.

## RAG

Чанк — секция markdown от заголовка `#`, `##` или `###` до следующего. Заголовки внутри фенсов не режут текст. Секция длиннее 1400 символов делится по абзацам с перекрытием около 180 символов.

Документы эмбеддятся с префиксом `search_document: `, вопрос — с `search_query: `. Так просит модель `nomic-embed-text`. Запрос идёт в Ollama:

```
POST http://10.10.1.101:11434/api/embed
{"model":"nomic-embed-text","input":["search_query: как устроен проект"]}
```

Ответ — массив из 768 чисел. Похожесть — косинус. Порог отсечения 0.05. Если вектора нет (Ollama молчит или кэш пуст и сеть умерла), тот же вопрос ищется по пересечению слов. Это режим `lexical`. Смесь закэшированных и новых векторов — режим `mixed`.

Кэш `data/rag/index.json` хранит векторы по id чанка. Правка одного файла пересчитывает только его секции. Индекс прогревается в фоне при старте сервера и достраивается на первом `/help`, если прогрев ещё идёт.

В индекс не входят исходники Go, JSON памяти и diff. Исходники в вопрос не подмешиваются: для живого дерева есть `list_files`, для правок — `git_diff`.

## Чего ассистент не делает

- Не коммитит и не переключает ветку. Инструменты только читают.
- Не отвечает на кулинарный вопрос, если перед ним нет `/help`. Такой текст идёт прежнему агенту.
- Не подмешивает найденные чанки в следующие обычные реплики.
