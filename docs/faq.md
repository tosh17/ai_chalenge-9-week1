# Сервисы s1

Домашний сервер `10.10.1.101`, пользователь SSH `troot`. Пароли в этот репозиторий не пишутся.

## GitLab

Контейнер `gitlab`. Веб слушает `http://10.10.1.101:8929`, git по SSH на порту `2224`. Статус healthy значит, что внутренние проверки GitLab проходят и страница должна открываться из домашней сети. Если контейнер Up, а браузер молчит, смотреть хвост `service_logs` и что в `list_services` есть порт `8929`.

## Ollama

Контейнер `ollama`, порт `11434`. Для эмбеддингов используется модель `nomic-embed-text`, её окно обучения `n_ctx_train=2048`. Если в логе есть `requested context size too large` и `num_ctx=8192`, запрос просит контекст больше окна модели. Контейнер при этом может оставаться Up: предупреждение не значит, что сервис упал.

## Runner

Контейнер `gitlab-runner`, имя раннера `local`, executor docker, сеть `lab`. Одновременно выполняется одна джоба. Пока она идёт, следующая стоит в pending. Это не поломка репозитория.
