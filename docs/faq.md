# Сервисы s1

Домашний сервер `10.10.1.101`, пользователь SSH `troot`. Пароли в этот репозиторий не пишутся.

## GitLab

Контейнер `gitlab`. Веб слушает `http://10.10.1.101:8929`, git по SSH на порту `2224`. Статус healthy значит, что внутренние проверки GitLab проходят и страница должна открываться из домашней сети. Если контейнер Up, а браузер молчит, смотреть хвост `service_logs` и что в `list_services` есть порт `8929`. Это не блокировка пользователя в CRM.

## Ollama

Контейнер `ollama`, порт `11434`. Для эмбеддингов используется модель `nomic-embed-text`. Долгий ответ чаще значит, что модель ещё грузится или контейнер перезапускается, а не что пользователя отключили.

## Runner

Контейнер `gitlab-runner`, имя раннера `local`, executor docker, сеть `lab`. Одновременно выполняется одна джоба. Пока она идёт, следующая стоит в pending. Это не поломка репозитория.
